Cache Management

MEMOPYK uses server-side caching to ensure fast page loads for hero videos, gallery videos, and images. This page shows what's cached, how much storage is used, and lets you manually refresh or clear the cache when needed.

Storage Management Overview

The card at the top shows cache health at a glance:

  • Cache Usage � Current size vs. limit (e.g., 303.9MB / 1000.0MB). The percentage badge shows how full the cache is.
  • Auto Cleanup � Automatic expiration period (30 days). Files older than 30 days are purged automatically.
  • Media Files � Total count of cached videos and images.

  • ?? Smart Cleanup (blue) � Removes expired files older than 30 days and orphaned files only.

Below the buttons: total content count (videos + images) and total size. Recommended after each production deployment.

Tips

  • Hero videos are marked Critical because the homepage loads immediately on first visit. These should always be cached.
  • The 30-day auto cleanup prevents cache bloat. If you need longer retention, contact your administrator.
  • If cache usage exceeds 80% (800MB), consider clearing old gallery videos that are no longer used.
  • The cache is stored on the server filesystem, not in the database.
