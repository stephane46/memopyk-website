Microsoft Clarity

View heatmaps and session recordings of how visitors use your website. Clarity helps you see where people click, scroll, and interact.

🚀 Getting Started

This screen shows your Clarity integration status. If Clarity is configured, you'll see a green dot, your Project ID, and a button to open the dashboard. The dashboard opens in a new tab where you can watch session replays and view heatmaps.

What Is Clarity?

Microsoft Clarity is a free tool that records visitor sessions and creates visual heatmaps showing:

  • Where visitors click most often
  • How far down the page they scroll
  • Which areas get the most attention
  • Session replays showing exact mouse movements

Configuration Status

The screen shows whether Clarity is set up:

  • Green dot + "Clarity is configured" - Ready to use
  • Gray dot + "Not configured" - Not set up yet

When Configured

If Clarity is active, you will see:

  • Your Project ID displayed in a gray code box (e.g., "Project ID: k4xx2nszd")
  • Open Clarity Dashboard button - Click to view heatmaps and recordings in a new tab

When Not Configured

If Clarity is not set up, you will see instructions to enable it. Contact your administrator to configure Clarity tracking.

What You Can Do in Clarity

The Clarity dashboard (opens in new tab) provides:

  • Heatmaps - Visual maps showing click and scroll patterns. See which buttons get the most attention.
  • Session Recordings - Replay actual visitor sessions to see their experience. Watch how people navigate your site.
  • Insights - Automatic detection of rage clicks (repeated clicking on the same spot), dead clicks (clicks that do nothing), and quick backs (visitors who leave immediately).
  • Filters - Filter by country, device type, or specific pages to analyze different visitor segments.

💡 Tips

  • Use heatmaps to see which call-to-action buttons get the most attention
  • Watch session recordings to find usability issues - look for hesitation, confusion, or repeated clicks
  • Look for rage clicks (repeated clicking) - they indicate frustration or broken features
  • Clarity data complements Google Analytics - use both together for a complete picture
  • Filter sessions by country to understand regional differences in visitor behavior
