Partners Directory

Manage the professional digitization partners displayed in the partner directory on the website.

🚀 Getting Started

All your digitization partners are listed in the table below. Use the filters to find partners by name, city, status, or service type. Each partner can be approved, rejected, or set to show on the public map. Click Add Partner to create a new entry manually, or Import TSV to bulk import from a spreadsheet.

Header Buttons

  • Add Partner — Create a new partner entry manually (opens a 4-tab form: Basic Info, Location, Services, Visibility)
  • Import TSV — Bulk import partners from a tab-separated spreadsheet (paste TSV data with header row)
  • View Map — Open the public partner directory map in a new tab to see how partners appear to visitors
  • Download Excel — Export all partners as a downloadable spreadsheet for offline editing or backup

Filters

  • Search — Filter by partner name or city. Type and results update instantly.
  • Status dropdown — All, Pending, Approved, or Rejected
  • Type dropdown — All, Digitization, Restoration, or Transfer

Table Columns

  • Date — Submission date (sortable)
  • Partner — Company name (sortable)
  • Type — Service type badge (sortable)
  • Contact — Contact name and email
  • Location — City and country (sortable)
  • Status — Click the badge to cycle: Pending, Approved, Rejected (sortable)
  • Active — Click to toggle Active/Inactive
  • Show on Map — Click to toggle On Map/Hidden. Only partners set to "On Map" appear in the public directory.
  • Actions — Edit (pencil) and Delete (trash) buttons

Partner Statuses

  • Pending — New submission awaiting review
  • Approved — Visible in the directory (if also Active and On Map)
  • Rejected — Not shown to visitors

Edit Partner Form

The edit dialog has 4 tabs:

  • Basic Info — Name, type, status, contact, email/phone visibility, website, description
  • Location — Address, city, postal code, country, latitude/longitude
  • Services — Photo/film/video format checkboxes and delivery methods
  • Visibility — Active toggle, Show on Map toggle, URL slug

Public Map Features

The public partner directory uses an interactive map powered by Mapbox:

  • Zoom/Pan Controls - Use mouse wheel to zoom, click and drag to pan. Zoom buttons appear in the top-right corner.
  • Marker Clusters - When multiple partners are close together, they group into a numbered circle. Click to expand.
  • Partner Cards - Click any map pin to see the partner's details, services, and contact info.
  • Show on Map Toggle - Controls whether a partner appears as a pin on the public map. Use this to temporarily hide partners without deleting them.

💡 Tips

  • Set partners to "Approved" and "On Map" to make them visible to the public
  • Use the View Map button to preview how partners appear to visitors
  • Click the "Show on Map" toggle to quickly hide a partner without changing their Approved status
  • Download Excel regularly to keep a backup of your partner database
