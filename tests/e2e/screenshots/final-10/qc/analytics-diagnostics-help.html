Diagnostics

Check the health of your website backend services. This screen helps you verify that all systems are running properly.

Action Buttons

  • Refresh button at top right - Reload all diagnostic data

Status Cards

Four cards show the health of critical services:

1. Server Card
  • Status: Healthy (green checkmark) or error (red X)
  • Version number (e.g., v1.0.0)
2. Database Card
  • Connection status: Connected (green) or Disconnected (red)
  • Response time in milliseconds (lower is better)
3. Uptime Card
  • How long the server has been running since last restart
  • Shown in days (d), hours (h), and minutes (m)
4. Analytics Card
  • DB ON/OFF badge - Internal analytics tracking status
  • GA4 ON/OFF badge - Google Analytics connection status
  • Green = working, Yellow/Red = issue

Cache Storage Section

Shows how much media storage is being used:

  • Video Cache - Number of video files and total size
  • Image Cache - Number of image files and total size
  • Total Usage - Overall percentage used with progress bar

The usage bar changes color based on capacity:

  • Green - Below 50% (healthy)
  • Yellow - 50-80% (moderate)
  • Red - Above 80% (high, may need cleanup)

Auto-Refresh

Diagnostic data refreshes automatically:

  • Health checks: every 30 seconds
  • Cache breakdown: every 60 seconds

The Last checked timestamp at the bottom shows when data was last updated.

What to Look For

  • All status cards should show green checkmarks
  • Database response time should be under 100ms
  • Cache usage should stay below 80%
  • Both DB and GA4 badges should be ON (green)

Tips

  • If any service shows red, contact your administrator
  • High cache usage may slow down the site - clear old media if needed
  • Check this screen after deploying updates to verify everything still works
  • Uptime resets to zero after server restarts (normal during updates)
